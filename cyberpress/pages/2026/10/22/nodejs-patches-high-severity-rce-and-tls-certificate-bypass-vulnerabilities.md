The Node.js Project released security updates on October 21, 2026, addressing ten vulnerabilities across its 26.x, 24.x, and 22.x release lines. The fixes cover remote code execution, TLS certificate verification bypasses, DNS handling, cryptographic randomness, and filesystem permission weaknesses. Patched releases are Node.js 26.12.1, 24.22.1, and 22.23.4.
